## Outcome-blind analysis rule

The analysis specification follows the executed [metric aggregation](../../../experiments/hung_sprint2/evaluation.py), [paired-result builder](../../../tools/hung_results.py), [Development audit](../../../tools/hung_development_audit.py) and [seed stability audit](../../../tools/hung_development_seed_stability.py). Each run's MAE/RMSE uses complete scored 24-hour days in original kWh, with RMSE from total squared error per hour. Pair only exact common scored days and label hashes within entity, budget and seed. Average seed-level paired differences within station, then stations equally within dataset/city/budget/method/reference. Transfer Gain and NTR are defined only against Target-only for source-using methods. A zero Target-only MAE gives null relative gain and a reported absolute difference. A zero-scored run gives null metrics; missing cells, unpaired days and late/incomplete labels remain explicit null or blocked records, never zeros or imputed outcomes.
